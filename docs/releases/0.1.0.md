# MindIE Agent `0.1.0` 正式版发布说明（First Official Milestone Release）

[English](0.1.0.en.md) · [文档中心](../README.md) · [版本兼容与无感更新](../release-compatibility-and-update.md)

**`v0.1.0` 是 MindIE Agent 的首个正式里程碑版本（First Official Milestone Release）。**

本版本完整汇总并固化了 MindIE Agent 从早期内测预览版（[`0.0.1`](0.0.1.md) $\to$ [`0.0.2`](0.0.2.md) $\to$ [`0.0.3`](0.0.3.md)）到生产级昇腾（Ascend NPU）AI Infra 智能研发底座的全部架构演进与工程能力：全面适配 **4 大原生编码宿主客户端**（`Claude Code`、`OpenAI Codex CLI`、`Kimi Code CLI`、`DeepSeek Harness`），交付 **7 大共享运行时与性能分析/建模组件**（`remote-dev`、`knowledge`、`diagnostics`、`coordinator`、`npu-top`、`profiler`、`sim`）及真机端到端评测底座 **`mindie-bench`**，随附 **7 大昇腾公共领域知识库（共 `450` 个 `L1–L4` 分级知识单元）**，并在 **`codex + gpt-6.1-sol (xhigh)`** 与 **`dsh + deepseek-flash (max)`** 双主力模型、**18 个真实昇腾工程任务（109 场端到端 Trial，含 `Ascend950DT` 实机 NPU）** 以及 **macOS / 4090 WSL2 / Windows 11 PowerShell 三平台（`15,595+ passed, 0 failed`）** 上完成了系统性价值量化验证。

> [!IMPORTANT]
> **专项深度报告与作者自述入口**
> - 🧭 **作者自述与架构设计哲学**：为什么我们砍掉传统多 Skill（“去 Skill 化”）、不做重型自研 Harness 与独立 UI，而是将能力正交拆解为“单一职责 MCP 工具 + `L1–L4` 分级知识飞轮（含 `L4` RSI 开放探索）”，以及关于人机协同（“高精地图自动驾驶”与“编译器 vs. 许愿机”）的完整思考与致谢 $\to$ **[`docs/releases/0.1.0/design-philosophy.md`](0.1.0/design-philosophy.md)**（[English](0.1.0/design-philosophy.en.md)）
> - 📊 **18 个真实任务全组件价值实测、完整 Prompt 与复现指南**：双模型在 `G0–G4` 五级消融梯度下的逐任务耗时/Token 明细、7 大组件价值归因、全部 18 个任务的 `instruction.md` 原词及四步复现命令 $\to$ **[`docs/releases/0.1.0/value-results.md`](0.1.0/value-results.md)**

### 1. 原生宿主适配层（4 个 Harness 插件：`cc` / `codex` / `kimi` / `dsh`）
- **“去 Skill 化”与单一入口（`/mindie-agent` + `rsi-explore`）**：将传统多 Skill 正交拆解为常驻对等工具（`remote-dev` 默认自动触发）与按需检索知识（单一 `/mindie-agent` 入口 + `rsi-explore` 开放探索入口），避免数百个 Skill 描述污染宿主上下文。
- **四阶段闭环生命周期与统一授权开关（`mindie-consent.json`）**：覆盖 `SessionStart` 非阻塞就绪与 `< 500ms` 空闲原子切换 $\to$ 任务期渐进式检索与远端执行 $\to$ `Stop` 异步公开对话提取、正则 + `Gitleaks` 双层隐私脱敏与 `C6` 经验蒸馏 $\to$ 单一 Opt-in 贡献与故障上报开关（默认关闭，撤回授权立即中断外发并清空待发队列）。
- **三端九环境进程树与环境隔离**：在 macOS (`launchd`)、Linux/WSL2 (`systemd >= 254` 控制组回收) 与原生 Windows 11 PowerShell (`Job Object` `KILL_ON_JOB_CLOSE` + `Task Scheduler` + 短路径 venv) 上实现零宿主机污染与确定性子进程回收。

### 2. 领域知识与经验自进化系统（`knowledge v0.13.0` + 7 大昇腾公共知识库 `450` 单元）
- **7 大昇腾公共知识库与 `L1–L4` 四级认知分层（`mindie-graded-unit/1`）**：覆盖 `infer-core` (`109`)、`operators` (`105`)、`vllm-ascend` (`91`)、`infer-distributed` (`39`)、`infer-observability` (`39`)、`infer-ops-compat` (`34`)、`agent-engineering` (`33`) 共 **`450` 个分级单元**，将 `L1`（硬件/框架刚性约束）、`L2`（故障判据与标准微流程 SOP）、`L3`（多阶段工程工作流）与 `L4`（深度调优变异算子）同证据强度正交解耦。
- **两阶段渐进式披露与 `< 8,000` Tokens 预算门控**：通过 `knowledge_query`（`< 1.2 KB` 摘要与 `applicability` 前提）$\to$ `knowledge_explain`（按需分段精读）攻克 `0.0.2` 长上下文拖慢问题，单任务读取严格受控在 **`4,814–5,599` tokens**，跨任务复用（`k=8`）净节省 **`+77,280 ~ +89,120` tokens**。
- **`G3` 经验飞轮与 `G4` 去先验锚定探索（`mode="explore"`）**：`G3` 通过 `Stop` 采集 + `C6` 蒸馏自动将新排障轨迹转化为可复用契约；`G4` 在开放调优中自动剥离既有 `L3/L4` 具体分支以消除先验锚定，仅挂载 `L1–L3` 物理边界与 `L4` 变异因子图谱，配合 `experiment-ledger.jsonl` 留一法消融验证正交收益。

### 3. 七大共享运行时、可观测与性能建模组件
- **`remote-dev` (`v0.10.4`)**：提供与本地工具 1:1 同构的远端文件读写、补丁应用、Git、搜索与流式后台长作业管理，搭载 SSH ControlMaster 复用、独立超时预算与 `completed / failed / unknown` 诚实副作用记账。
- **`coordinator` (`v0.6.2`) & `npu-top` (`v0.2.1`)**：提供 SQLite WAL 多 Agent 选卡/端口租约仲裁（`0` 冲突，`~2.1 ms` 接管）、昇腾 A2 / A3 双 Die `Phy-ID 0..15` / A5 (`Ascend950DT`) 拓扑预检、Docker 容器 `/proc` 进程穿透、DCMI 降频解码与跨机编译缓存复用。
- **`profiler` (`v0.5.0`) & `sim` (`v0.7.0`)**：`profiler` 支持 `msprof` SQLite 毫秒级就地只读解析（`db_mutation = False`），100% 分离慢链路（`Comm`）与慢卡（`Attention`）并实现 `99%` 峰值显存归因（残差 `0.5% < 10%` 门禁）；`sim` 提供 A2/A3/A5 四层 Roofline 求解、算子流水排布、`192 KiB` UB 容量融合筛查及经 A3 实机校准的整网 TPOT 预测（误差 `-4.14%`，优于 `±15%` 门禁）。
- **`diagnostics` (`v0.5.1`) & `mindie-bench` (`v0.4.1`)**：`diagnostics` 支持多卡 CANN/`plog` 级联报错确定性根因分诊（100% 锁定首发根因 Rank 并剥离衍生 `HCCL` 超时 Rank）、强制双层脱敏与指纹去重；`mindie-bench` 支持四大宿主插件 `G0–G4` 全阶梯真机评测与组件价值归因。

从 `0.1.0` 起，MindIE Agent 采用 **`0.Y.0` 特性里程碑 + `0.Y.Z` 通道清单热修（[`channels/0.1.json`](../../channels/0.1.json)）** 机制：当单个底层组件发布 `0.1.1` / `0.1.2` 缺陷修复时，只需更新 `channels/0.1.json` 中对应组件的版本与 Commit SHA，客户端即可通过 **故障触发即时自愈检查**、**1 小时 HTTP `ETag` 轮询**或 **后台增量同步**拉取单包 `uv` 更新，并在 `< 500ms` 空闲窗口内完成原子切换，无需连坐重发 4 个宿主插件（详见[版本兼容与无感更新](../release-compatibility-and-update.md)）。
