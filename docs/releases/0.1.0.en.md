# MindIE Agent `0.1.0` Official Release Notes (First Official Milestone Release)

[中文](0.1.0.md) · [Documentation Center](../README.en.md) · [Release Compatibility & Silent Update](../release-compatibility-and-update.en.md)

**`v0.1.0` is the First Official Milestone Release of MindIE Agent.**

This release consolidates the entire architectural evolution from our internal preview releases ([`0.0.1`](0.0.1.en.md) $\to$ [`0.0.2`](0.0.2.en.md) $\to$ [`0.0.3`](0.0.3.en.md)) into a production-ready Ascend NPU AI Infra harness and runtime ecosystem: native integration across **4 coding agent hosts** (`Claude Code`, `OpenAI Codex CLI`, `Kimi Code CLI`, `DeepSeek Harness`), **7 shared runtime, observability, and performance modeling components** (`remote-dev`, `knowledge`, `diagnostics`, `coordinator`, `npu-top`, `profiler`, `sim`) plus the end-to-end benchmark runner **`mindie-bench`**, **7 public Ascend domain knowledge corpora (`450` `L1–L4` graded knowledge units)**, and systematic real-task benchmark validation across **`codex + gpt-6.1-sol (xhigh)`** and **`dsh + deepseek-flash (max)`** (**18 real engineering tasks, 109 end-to-end trials including live `Ascend950DT` NPUs**) as well as **macOS / 4090 WSL2 / Windows 11 PowerShell (`15,595+ passed, 0 failed`)**.

> [!IMPORTANT]
> **In-Depth Reports & Author's Note**
> - 🧭 **Author's Note & Architectural Philosophy**: Why we eliminated multi-Skill sprawl ("de-skilling"), avoided building a heavy custom Harness or standalone UI, split capabilities orthogonally into "Single-Responsibility MCP Tools + `L1–L4` Graded Knowledge Flywheel (with `L4` RSI open-ended exploration)", and how we view human-Agent synergy ("HD-Map Autopilot" and "Compiler vs. Wishing Machine") $\to$ **[`docs/releases/0.1.0/design-philosophy.en.md`](0.1.0/design-philosophy.en.md)** ([中文完整版](0.1.0/design-philosophy.md))

### 1.1 Native Host Adaptation Layer (4 Harness Plugins: `cc` / `codex` / `kimi` / `dsh`)
- **"De-Skilling" & Single Entry Point (`/mindie-agent` + `rsi-explore`)**: Orthogonally splits traditional Skills into always-on peer MCP tools (`remote-dev`) and on-demand graded knowledge (`/mindie-agent` + `rsi-explore`), preventing hundreds of Skill descriptions from polluting host context windows.
- **Four-Stage Lifecycle & Unified Opt-In Consent (`mindie-consent.json`)**: Covers `SessionStart` non-blocking readiness & `< 500ms` idle atomic cutover $\to$ task-time progressive retrieval & remote execution $\to$ `Stop` async transcript capture, regex + `Gitleaks` dual-layer redaction & `C6` distillation $\to$ a single opt-in switch (OFF by default; revoking consent immediately halts outbound knowledge/fault delivery and purges queues).
- **Three-OS Nine-Environment Process-Tree & Environment Isolation**: Deterministic subprocess tree cleanup and isolated virtual environments across macOS (`launchd`), Linux/WSL2 (`systemd >= 254` cgroups), and native Windows 11 PowerShell (`Job Object` `KILL_ON_JOB_CLOSE` + `Task Scheduler` + short-path venvs).

### 1.2 Domain Knowledge & Self-Evolving Flywheel (`knowledge v0.13.0` + 7 Public Ascend Corpora, `450` Units)
- **7 Public Ascend Corpora & `L1–L4` Graded Hierarchy (`mindie-graded-unit/1`)**: Spans `infer-core` (`109`), `operators` (`105`), `vllm-ascend` (`91`), `infer-distributed` (`39`), `infer-observability` (`39`), `infer-ops-compat` (`34`), and `agent-engineering` (`33`) for **`450` graded units**, orthogonally decoupling `L1` (hardware/framework invariants), `L2` (fault signatures & micro-SOPs), `L3` (multi-stage workflows), and `L4` (exploration mutators) from evidence strength.
- **Two-Stage Progressive Disclosure & `< 8,000` Token Budget Gate**: `knowledge_query` (`< 1.2 KB` compact cards with `applicability` preconditions) $\to$ `knowledge_explain` (on-demand section reads) resolves the `0.0.2` context overhead, bounding per-task reads to **`4,814–5,599` tokens** and delivering **`+77,280 to +89,120` tokens** in net savings at `k=8`.
- **`G3` Experience Flywheel & `G4` De-Anchored Exploration (`mode="explore"`)**: `G3` automatically distills verified bugfixes into reusable `L1–L3` contracts via `C6`; `G4` strips existing `L3/L4` recipes in open-ended tuning to prevent prior anchoring, mounting `L1–L3` physical limits and `L4` `factor_graph` mutators verified via `experiment-ledger.jsonl` leave-one-out ablation.

### 1.3 Seven Shared Runtime, Observability & Modeling Components
- **`remote-dev` (`v0.10.4`)**: 1:1 local-isomorphic remote file, patch, Git, search, and streaming background job tools over multiplexed SSH ControlMaster connections, with independent timeout budgets and `completed / failed / unknown` side-effect accounting.
- **`coordinator` (`v0.6.2`) & `npu-top` (`v0.2.1`)**: SQLite WAL multi-Agent device/port lease arbitration (`0` conflicts, `~2.1 ms` handoff), Ascend A2 / A3 dual-Die `Phy-ID 0..15` / A5 (`Ascend950DT`) topology pre-checks, Docker `/proc` container ownership resolution, DCMI throttling decoding, and cross-host build cache reuse.
- **`profiler` (`v0.5.0`) & `sim` (`v0.7.0`)**: `profiler` delivers millisecond in-place read-only `msprof` SQLite analysis (`db_mutation = False`), 100% separation of slow links (`Comm`) from slow ranks (`Attention`), and `99%` peak HBM attribution (`0.5% < 10%` residual gate); `sim` provides A2/A3/A5 4-layer Roofline modeling, operator pipeline scheduling, `192 KiB` UB fusion screening, and calibrated A3 network TPOT prediction (`-4.14%` error, well within `±15%`).
- **`diagnostics` (`v0.5.1`) & `mindie-bench` (`v0.4.1`)**: `diagnostics` provides deterministic multi-rank CANN/`plog` cascade root-cause triage (100% isolating originating faults from cascading `HCCL` timeouts), mandatory dual-layer redaction, and fingerprint deduplication; `mindie-bench` drives `G0–G4` evaluation across all four host plugins.

Starting with `0.1.0`, MindIE Agent adopts a **`0.Y.0` Feature Milestone + `0.Y.Z` Release Channel Manifest ([`channels/0.1.json`](../../channels/0.1.json))** mechanism: when a single shared component ships a `0.1.1` / `0.1.2` bugfix, updating its version and commit SHA in `channels/0.1.json` rolls out an incremental `uv` single-package update via **fault-triggered immediate self-healing**, **1-hour HTTP `ETag` polling**, or **background sync**, switching atomically in `< 500ms` during an idle window without republishing all four Harness plugins (see [Release Compatibility & Silent Update](../release-compatibility-and-update.en.md)).
