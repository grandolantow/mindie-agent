## 3. Verified Core Capabilities

1. **Native Installation & 24-Hour Silent Compatible Updates**:
   - First-time installation pins the immutable `v0.0.1` tag; more than 24 hours after the last successful check, routine use asynchronously selects the highest compatible ordinary Release, builds the locked `uv` environment in the background, and switches atomically when idle while preserving existing consent.
2. **Remote Ascend Execution & Local Experience Loop**:
   - All six environments completed real remote SSH operations via `remote-dev`, deterministic public dialogue extraction, Gitleaks + privacy-rule redaction, small-model navigation indexing, and local ReMe search verification.
3. **Public Contribution, Bot Review & Incremental Sync**:
   - Verified end-to-end public PR creation, Grok Bot safety review and merge into [`knowledge-vllm-ascend`](https://github.com/mindie-agent/knowledge-vllm-ascend), incremental client sync (661 task packages), and `helpful` feedback submission.
4. **Bounded Local Diagnostics & Opt-In Issue Reporting**:
   - Verified bounded local structured log rotation, cross-task fault fingerprint deduplication, and opt-in GitHub Issue fault reporting.
5. **DeepSeek Harness Native Integration (Addendum Acceptance)**:
   - On macOS 27.0.1 arm64, 4090 WSL (Ubuntu 24.04), and Lenovo native Windows + DSH `0.2.0-rc.2`, verified Host-row composition (no shipped row or preset override), native `/mindie-agent` entry (`init`/`status`/`choose`/`deactivate`), DSH v4 Stop public-transcript capture + redaction, DSH-model summary indexing, auto-fork contribution (PR #51), `knowledge_query` / `knowledge_explain` / `knowledge_feedback` / `knowledge_sync`, diagnostics reporting controls, silent auto-update (stable launcher + immutable generations + atomic pointer live swap), and registration plus visible failure behavior of the official `remote-dev` MCP tools.

## 4. Known Limitations in `0.0.1`

- **OpenAI Codex CLI Child-Agent (`spawn_agent`) Interruption**:
  - When OpenAI Codex CLI interrupts a child agent (`spawn_agent`), Codex currently aborts the waiting handle without delivering a cancellation signal to an in-flight MCP tool call inside the child agent, which can leave a local helper/SSH subprocess or one-shot remote command running until completion (main-thread tool cancellation in Codex and standard cancellation in Claude Code work as expected).
  - MindIE Agent documents this upstream host limitation transparently rather than adding intrusive process-hunting watchers or arbitrary business timeouts. Persistent background jobs remain explicitly controllable via `remote-dev` (`job_cancel`). We have shared a minimal reproduction and fix analysis upstream at [openai/codex#26956](https://github.com/openai/codex/issues/26956#issuecomment-6205886409).
- **Benchmark Scope**:
  - End-to-end business quality and efficiency benchmarks are tracked separately; `0.0.1` makes no premature quantitative speedup claims.
- **DSH `0.0.1` Known Limits**:
  - Silent auto-update checks and swaps child plugins while the DSH Host is alive without registering an OS scheduler for stopped DSH installations; generation swaps update launcher/host tools without regenerating the initial bundle patch or Skills. See [`mindie-agent-dsh/docs/verification.md`](https://github.com/mindie-agent/mindie-agent-dsh/blob/main/docs/verification.md) for full details.
